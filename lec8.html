1. 贝叶斯框架下的假设检验

1.1 传统的假设检验方法(NHST)

🧑‍💻先简单回顾一下传统统计中的零假设显著性检验（Null Hypothesis Significance Test, NHST）。

NHST基于概率性的反证法：首先建立零假设的前提，然后认为小概率事件(发生概率小于0.05的事件)在单次抽样或实验中不会发生。

NHST中，研究者需对总体做互斥的两种假设，即零假设\(H_0\)和备择假设\(H_1\)：

零假设（Null Hypothesis，\(H_0\)）：没有效应或差异的假设。在许多情况下，零假设代表”无差异”或”无效应”。例如，认为两组数据所代表的总体参数没有差异。

备择假设（Alternative Hypothesis，\(H_1\)）：表示零假设不成立时的假设，通常认为有显著效应或差异。

NHST的核心概念还包括：

  • Alpha（\(\alpha\)）：显著性水平，常设为 0.05，在零假设（\(H_0\)）为真时错误拒绝零假设（\(H_0\)）能够接受的犯错的概率。即能接受的最高的一类错误（\(\alpha\)）率（假阳性）。

  • \(p\)值：在零假设为真的前提下，观察到当前或更极端数据的概率。如果 \(p\) 值小于等于 \(\alpha\)，则拒绝零假设，认为数据支持备择假设。

  • \(统计检验力(statistical power)\): 当零假设不为真（即备择假设为真时），拒绝零假设的概率。

  • NHST依赖于 \(p\) 值，其应用极其广泛，但也存在误解和滥用：

    1. 假阳性结果：研究者可能会操纵 \(p\) 值，如增加样本量或调整变量，导致假阳性长高。   

    2. 忽视效应大小：\(p\) 值无法提供效应大小的信息，仅是显著与否的二分判断，不能全面反映数据的实际意义。       

    3. 不考虑先验信息：忽略了先验知识和理论背景，无法有效利用已有的研究成果。

    4. 无法为直接为零假设提供支持：不显著结果不代表零假设为真。

1.3 贝叶斯框架下的假设检验优势

与传统假设检验方法相比，贝叶斯框架下的方法具有以下几方面的优势：

  1. 可以对假设一视同仁： 同时评估\(H_0\)和\(H_1\)的可能性。 

  2. 结合先验信息： 贝叶斯因子分析可以利用先验知识，将前人的研究成果与当前数据结合，提供更为全面的证据评估。       

  3. 支持多模型比较： 贝叶斯因子不仅适用于二元假设检验，还可以用于比较多个模型的适用性，提供更为灵活的统计分析工具。

  4. 可以直接支持零假设: 能够为\(H_0\)提供支持证据，解决传统假设检验难以证明\(H_0\)成立的问题。

以Beta-Binomial模型在Stan中的实现为例

仍然以随机点运动任务为例，每个试验中参与者判断正确的概率用 \(\theta\) 表示。

模型假设

  • 判断正确概率 \(\theta\) 服从 Beta 分布：

\[ \begin{equation} \theta \sim \mathrm{Beta}(\alpha, \beta) \end{equation} \]

  • 在每次试验中，参与者的成功次数 \(Y\) 服从 Binomial 分布：

\[ \begin{equation} Y \sim \text{Binomial}(n, \theta) \end{equation} \]

其中，\(n\)是试验的总次数，\(Y\)是成功次数。

模型设定

在这个例子中，我们可以使用Beta-Binomial 模型来表示：

数据: 来自 data/beta-binmial.csv（118 次判断、正确 99 次），即 \(n = 118\)、\(Y = 99\)
先验分布为：\(\theta \sim \mathrm{Beta}(2, 2)\)
似然函数为：\(Y|\theta \sim \text{Bin}(n, \theta)\)

# 采样结果缓存：tmpdata/ 下已有同名 .rds 就直接读取；换个文件名或删掉即可重跑
cache_rds <- function(path, code) {
  dir.create(dirname(path), showWarnings = FALSE, recursive = TRUE)
  if (file.exists(path)) {
    readRDS(path)
  } else {
    value <- code
    saveRDS(value, path)
    value
  }
}

2. 基于后验分布的统计推断

2.1 将 HDI 与 零点 进行比较

在上述例子中，我们要将后验分布与“零点”，即随机水平进行比较。

可利用 后验分布的 HDI（Highest Density Interval），比如 95% HDI。

计算 HDI

HDI 所定义的区间 \([\theta_\text{low}, \theta_\text{high}]\) 满足以下条件：


1. 对于任何 \(\theta\) 在区间 \([\theta_\text{low}, \theta_\text{high}]\) 外的点，它的密度都小于区间内的点的密度，即：


\(f(\theta_\text{low} | \alpha, \beta) = f(\theta_\text{high} | \alpha, \beta)\)


2. 该区间内的概率质量为 95%：

\(\int_{\theta_\text{low}}^{\theta_\text{high}} f(\theta | \alpha, \beta) d\theta = 0.95\)

通过代码提取上述后验的95% HDI：

推断结果：拒绝虚无假设 \(H_0: \theta = 0.5\)，认为成功率 \(\theta\) 不同于随机水平 0.5。

2.2 将 HDI 与 零区间 进行比较：HDI + ROPE

ROPE（Region of Practical Equivalence，实际等效区间）：研究者在实践中认为与零点无差异的区域。

结合 HDI 和 ROPE，可进一步检验成功率 \(\theta\) 是否在实践中不同于 0.5。

本例中，假定 ROPE 的范围为 \([0.4, 0.6]\)。

  • 如果成功率 \(\theta\) 的95% HDI 完全落入这个区间，则推断 \(\theta\) 在实践中与随机判断水平 0.5 等同。
  • 如果成功率 \(\theta\) 的95% HDI 完全不在这个区间，则推断 \(\theta\) 在实践上可能与 0.5 不同。
  • 如果成功率 \(\theta\) 的95% HDI 与这个区间部分重合，则当前数据无法推断 \(\theta\) 与0.5 是否相同

注意：ROPE需要我们根据具体情况进行调整。 一般情况下需要参考经验值或文献中的建议。 HDI + ROPE与基于零点的推断更加严格。

检验步骤

本例中，参数的 95% HDI 区间为 \([0.76, 0.89]\)。

参数的 95% HDI 与 ROPE 区间 \([0.4, 0.6]\) 比较：


- HDI 区间为 \([0.76, 0.89]\)。

- ROPE 区间为 \([0.4, 0.6]\)。

两者完全不重叠：该 95% HDI 整体位于 ROPE 的右侧。

# 零假设区间的后验概率质量（点零假设下为 0）
p_null_of <- function(samples, parts) {
  if (is.null(parts)) return(0)
  inside <- rep(FALSE, length(samples))
  for (r in parts) inside <- inside | (samples > r[1] & samples < r[2])
  mean(inside)
}

# ============================================
# 3. 绘图：阴影 = 零假设区间，虚线 = 边界
# ============================================
visualize_test_theta <- function(samples, test) {
  df <- data.frame(theta = samples)
  p0 <- p_null_of(samples, test$null_parts)

  g <- ggplot(df, aes(x = theta)) +
    geom_density(fill = "gray80", alpha = 0.5) +
    labs(
      title = test$name,
      subtitle = paste0(
        "Null: ", test$null_label, " | p(null) = ", sprintf("%.3f", p0), "\n",
        "Interest: ", test$interest_label,
        " | p(interest) = ", sprintf("%.3f", 1 - p0)
      ),
      x = expression(theta),
      y = "Posterior density"
    ) +
    papaja::theme_apa() +
    theme(
      plot.title = element_text(face = "bold", size = 10),
      plot.subtitle = element_text(size = 7),
      axis.title = element_text(size = 9)
    ) +
    xlim(0, 1)

  if (!is.null(test$null_parts)) {
    for (r in test$null_parts) {
      g <- g + annotate("rect", xmin = max(r[1], 0), xmax = min(r[2], 1),
                        ymin = 0, ymax = Inf,
                        alpha = 0.18, fill = "steelblue")
    }
  }
  if (!is.null(test$vlines)) {
    g <- g + geom_vline(xintercept = test$vlines, linetype = "dotted",
                        colour = "steelblue", linewidth = 0.8)
  }
  if (!is.null(test$note)) {
    g <- g + annotate("text", x = 0.02, y = Inf, hjust = 0, vjust = 1.8,
                      label = test$note, size = 2.6, colour = "grey30")
  }
  g
}

3. 基于贝叶斯因子的统计推断

贝叶斯假设检验的另一个做法：贝叶斯因子 (Bayes factor, BF)

贝叶斯因子（Bayes Factor，BF） 衡量不同模型的相对证据强度，通过比较模型间的后验概率来得出结论。

BF值主要用于比较零假设（\(H_0\)）与备择假设（\(H_1\)）的相对支持程度，其衡量的主要是数据在这两种假设下的解释能力。

贝叶斯因子的公式：

\[ \begin{align*} \text{Bayes Factor} &= \frac{\text{posterior odds }}{\text{prior odds }} \\ &= \frac{\text{后验概率比}}{\text{先验概率比}} \\ &= \frac{P(H_1 | Y) / P(H_0 | Y)}{P(H_1) / P(H_0)} \end{align*} \]

  • Posterior odds：后验概率比

  • Prior odds：先验概率比

  • \(H_0\)：零假设

  • \(H_1\)：备择假设

Heck, D. W., Boehm, U., Böing-Messing, F., Bürkner, P.-C., … Hoijtink, H. (2023). A review of applications of the bayes factor in psychological research. Psychological Methods, 28(3), 558–579. https://doi.org/10.1037/met0000454

BF值还有一种表达方式，即后验概率比等于贝叶斯因子乘以先验概率比：

\[ \begin{align*} \text{posterior odds} &= \text{BF}_{10} \times \text{prior odds} \end{align*} \]

因此，贝叶斯因子反映了先验概率到后验概率变化的程度或证据。

BF值在评估证据强度上的大致解读标准：

贝叶斯因子 解读
> 100 极强的证据支持\(H_1\)
30 ~ 100 非常强的证据支持\(H_1\)
10 ~ 30 较强的证据支持\(H_1\)
3 ~ 10 中等程度的证据支持\(H_1\)
1 ~ 3 较弱的证据支持\(H_1\)
1 没有证据
1/3 ~ 1 较弱的证据支持\(H_0\)
1/10 ~ 1/3 中等程度的证据支持\(H_0\)
1/30 ~ 1/10 较强的证据支持\(H_0\)

< 1/100 极强的证据支持\(H_0\)

Source: 该表改编自胡传鹏等(2018)，源引用于Lee & Wagenmakers (2014)。

  • \(BF_{10}\) = 1，收集到的数据并没有改变备择假设\(H_1\)的相对可能性

  • \(BF_{10}\) > 1，收集到的数据增加了备择假设\(H_1\)的相对可能性。\(BF\)越大，表明支持备择假设\(H_1\)的证据越强

  • \(BF_{10}\) < 1，收集到的数据削弱了备择假设\(H_1\)的相对可能性。\(BF\)越小，表明支持备择假设\(H_1\)的证据越弱

BF值不仅可以用于简单的假设检验，也可以用于比较复杂模型、评估模型拟合优度、以及在多模型比较中提供更丰富的信息。

贝叶斯因子同样可以应用于以下三种常见的假设检验方法：

  1. Testing against the point-null

贝叶斯因子可以用来检验某个参数是否等于零，即检验点的零假设。

  1. Testing against a null-region

设定一个”零区域”，即一个参数值的范围，该范围内的值被认为与零没有显著差异。

例如，\(\beta_1 \in [-0.05, 0.05]\) 为零区域，即认为 \(\beta_1\) 落在这个区间内是被认为等同于零。BF值可以量化数据支持 \(\beta_1\) 在零区域内（\(\beta_1 \in [-0.05, 0.05]\)）或零区域外（\(\beta_1 \notin [-0.05, 0.05]\)）的证据强度。

  1. Directional hypotheses

效应为正还是负。

例如，假定 \(H_1: \beta_1 > 0\)，认为自变量对因变量有正向影响。BF值可以帮助量化不同方向的证据强度。

3.1 与零点进行比较的BF值

在Beta-Binomial模型中，设定如下假设

  • 零假设 \(H_0: \theta = 0.5\)
  • 备择假设 \(H_1: \theta \neq 0.5\)

BF值衡量零假设和备择假设的相对证据。

\[ BF_{10} = \frac{P(\text{Data} | H_1)}{P(\text{Data} | H_0)} = \frac{P(Data|\theta \neq 0.5)}{P(Data|\theta = 0.5)} \]

其中，\(P(Data | H_1)\) 和 \(P(Data | H_0)\) 分别表示在备择假设\(H_1\)和零假设\(H_0\)下数据的似然值。

🔍 Savage-Dickey 公式来源

Savage-Dickey 密度比的标准形式是（见 Wagenmakers et al., 2010）：

\[ \text{BF}_{01} = \frac{p(\theta = 0.5 \mid \text{data}, \mathcal{M}_1)}{p(\theta = 0.5 \mid \mathcal{M}_1)} \]

其中：

  • 分子 \(p(\theta = 0.5 \mid \text{data}, M_1)\)：表示在备择模型 \(M_1\)（即包含参数 \(\theta\) 的模型）下，参数 \(\theta\) 在 0.5（原假设 \(H_0\) 指定的点）处的后验可能性。

  • 分母 \(p(\theta = 0.5 \mid M_1)\)：表示在备择模型 \(M_1\) 下，看到数据前，参数 \(\theta\) 在 0.5 处的先验可能性。

  • \(BF_{01}\)：是支持原假设（\(M_0\)） 相对于备择假设（\(M_1\)） 的证据。\(BF_{01}\) 的值越大，证据越支持原假设（即 \(\theta = 0.5\)）。

使用后验分布计算 \(\theta = 0.5\) 处的后验和先验概率密度：

Code

# 直接用解析密度；核密度估计在 1e-12 量级的密度处分辨不出（会得到 0）

posterior_at_null <- dbeta(0.5, shape1 = 101, shape2 = 21)

用桥采样（Bridge Sampling）计算同一个贝叶斯因子

JASP 的模型比较用的是桥采样：分别估计 \(H_0\)（\(\theta = 0.5\)，点零假设）与 \(H_1\)（\(\theta \sim \mathrm{Beta}(2, 2)\)）的边际似然，再取比值。

Code 
# H1：用后验样本 + 解析 log 后验密度做桥采样
log_post <- function(theta, data) {
  dbeta(theta, 2, 2, log = TRUE) + dbinom(data$Y, data$N, theta, log = TRUE)
}

samples_H1 <- matrix(theta_post, ncol = 1, dimnames = list(NULL, "theta"))

bridge_H1 <- bridgesampling::bridge_sampler(
  samples_H1,
  log_posterior = log_post,
  data = list(N = 118, Y = 99),
  lb = c(theta = 0),
  ub = c(theta = 1),
  silent = TRUE
)

# H0：θ 固定在 0.5，边际似然就是该点的似然
logml_H0 <- dbinom(99, 118, 0.5, log = TRUE)

BF01_bridge <- exp(logml_H0 - bridge_H1$logml)
BF10_bridge <- 1 / BF01_bridge

cat("BF_01 (bridge sampling) =", fmt_bf(BF01_bridge), "\n")

3.2 与零区域进行比较的贝叶斯因子

ROPE

  • 假设 \(\theta\) 的值在 \([0.4, 0.6]\) 时，我们将其视为等于 0.5 的等效区间。

ROPE 对于贝叶斯因子的意义

  • 通过设定零区域，我们可以计算零区域的先验概率和后验概率，进而计算贝叶斯因子来量化数据对假设的支持强度。

\[ BF_{10} = \frac{P(\text{Data} | H_1)}{P(\text{Data} | H_0)} = \frac{P(Data|\theta \notin [0.4,0.6])}{P(Data|\theta \in [0.4,0.6])} \]

基于零区域的贝叶斯因子的计算

首先，确定 \(\theta\) 在 ROPE 范围 \((0.4, 0.6)\) 内的概率，即：

\[ \begin{align*} P(H0|Y) &= P(0.4 \leq \theta \leq 0.6 | Y) = \int_{0.4}^{0.6} f(\theta | Y) d\theta \\ \end{align*} \]

  • 其中 \(f(\theta | Y)\) 是 \(\theta\) 的后验密度函数。根据我们的后验分布 \(Beta(101, 21)\)，我们可以使用积分或数值方法来求解具体数值。

然后，计算 \((0.4, 0.6)\) 之外的概率，即 \(P(\theta \notin (0.4, 0.6) | Y)\) ：

\[ P(H1|Y) = P(\theta \notin (0.4, 0.6) | Y) = 1 - P(H0|Y) \]

然后，根据下式计算基于零区域的贝叶斯因子（BF）：

\[ \text{BF}_{01} = \frac{P(R \mid Y)\,/\,P(R^c \mid Y)}{P(R)\,/\,P(R^c)}, \qquad R = (0.4, 0.6) \]

注意：区间假设下，先验落在 \(R\) 内的概率并不等于 0.5，所以不能把”后验概率比”直接当作贝叶斯因子，必须再乘上先验概率比 \(P(R^c)/P(R)\)。

R代码实现

对于 Beta 分布，使用其累积分布函数（CDF）计算 ROPE 内的后验概率：

\[ P(0.4 \leq \theta \leq 0.6 \mid Y) = F(0.6) - F(0.4) \]

Code 
# 区间假设：H0: θ ∈ [0.4, 0.6]（实用等效），H1: θ ∉ [0.4, 0.6]
p_rope_post  <- pbeta(0.6, 101, 21) - pbeta(0.4, 101, 21)   # 后验落在 ROPE 内
p_rope_prior <- pbeta(0.6, 2, 2)    - pbeta(0.4, 2, 2)      # 先验落在 ROPE 内

BF01_rope <- (p_rope_post / (1 - p_rope_post)) *
             ((1 - p_rope_prior) / p_rope_prior)
BF10_rope <- 1 / BF01_rope

cat("P(θ ∈ ROPE | Y)      =", fmt_bf(p_rope_post), "\n")
P(θ ∈ ROPE | Y)      = 2.13e-08
Code 
cat("P(θ ∈ ROPE)  (prior) =", fmt_bf(p_rope_prior), "\n")
P(θ ∈ ROPE)  (prior) = 0.30
Code 
cat("BF_01 =", fmt_bf(BF01_rope), " | BF_10 =", fmt_bf(BF10_rope), "\n")
BF_01 = 5.08e-08  | BF_10 = 1.97e+07

代入数值：\(P(\theta \in R \mid Y) \approx\) 2.13e-08，\(P(\theta \notin R \mid Y) \approx\) 1.00；先验落在 \(R\) 内的概率为 0.30，故先验比 \(P(R^c)/P(R) \approx\) 2.38。

于是有： \(\text{BF}_{01} \approx\) 5.08e-08、\(\text{BF}_{10} \approx\) 1.97e+07。

\(\text{BF}_{01} \ll 1\) 意味着数据强烈支持 \(H_1\)：\(\theta\) 落在 \((0.4, 0.6)\) 之外。注意这里与 3.1 的点零假设检验方向一致，只是把”\(\theta\) 是否等于 0.5”换成了”\(\theta\) 是否落在实用等效区间内”。

给定数据，后验集中在 0.83 附近，与观测到的 99/118 ≈ 0.84 一致；因此可以认为，成功率显著高于随机判断水平（0.5）。

练习1：

首先，可以写出”伪代码”作为计算的思路：

post_odds  <- theta_rope_prob / (1 - theta_rope_prob)
# 先验落在 ROPE 内的概率（复用 3.1 提取的 theta_prior）
prior_in   <- mean(theta_prior > rope_low & theta_prior < rope_high)
prior_odds <- prior_in / (1 - prior_in)
bf01 <- post_odds / prior_odds
cat("贝叶斯因子 BF₀₁（支持 theta 在 (0.4,0.6) 内）：", signif(bf01, 3), "\n")

Code 
# 请直接运行，无需修改
# 计算「区间内 / 区间外」的概率比（练习2用；region 默认取 ROPE = [0.4, 0.6]）
calculate_odds <- function(theta_samples, region = c(0.4, 0.6)) {
  # 区间内的样本
  in_range <- theta_samples[theta_samples >= region[1] & theta_samples <= region[2]]

  # 区间外的样本
  out_of_range <- theta_samples[theta_samples < region[1] | theta_samples > region[2]]

  # 区间内外的比例
  P_in_range <- length(in_range) / length(theta_samples)
  P_out_of_range <- length(out_of_range) / length(theta_samples)

  # 概率比（区间外 / 区间内）
  P_out_of_range / P_in_range
}

总结

贝叶斯统计较传统统计方法有很多优势，其中最突出的优势是对零假设和备择假设一视同仁。

  • 帮助研究者解决为零假设提供证据的问题
  • 帮助研究者灵活地检验各种假设的形式。

最后，请谨慎看待 \(BF\) 值，\(BF\) 值并不能告诉我们相信/不相信什么，而只是为你修正自己的信念提供参考。
