回顾：手动计算未归一化后验

概率编程语言的核心作用在于自动帮助我们进行后验采样，获得贝叶斯后验分布。

传统贝叶斯后验分布的推理中，我们不仅需要自己定义模型（似然函数、先验），还需要想办法获得后验如（MCMC）。

Code 
N <- 10
Y <- 9
theta <- seq(0, 1, length.out = 10000)
prior_density <- dbeta(theta, shape1 = 2, shape2 = 2)
likelihood <- dbinom(Y, size = N, prob = theta)
posterior_unstandardized <- likelihood * prior_density

手动实现 MCMC 时，需要对建议的参数样本计算未归一化后验，作为接受率。

回顾：在 Stan 中定义模型

在 Stan 中，定义先验和似然后，由采样器近似后验。

data {
  int<lower=0> N;
  int<lower=0, upper=N> Y;
}
parameters {
  real<lower=0, upper=1> theta;
}
model {
  theta ~ beta(2, 2);
  Y ~ binomial(N, theta);
}

Y ~ binomial(N, theta) 指定给定成功概率时观测成功次数的概率模型。

贝叶斯推断的核心术语（1）

  • 先验分布（Prior Distribution）：在观察数据之前，研究人员对模型中未知参数分布的初始估计。这种估计/信念可以基于现有研究或试点数据形成。

  • 似然函数（Likelihood Function）：数据的生成模型，即什么模型下可能会出现当前数据；可用来计算不同模型参数下出现当前数据的可能性（即似然）。

  • 后验分布（Posterior Distribution）：在观察到数据后，根据贝叶斯规则平衡先验知识与观测数据，对参数的更新信念。

  • 马尔可夫链蒙特卡洛方法（Markov Chain Monte Carlo, MCMC）：MCMC是一种通过模拟来推断后验分布的采样方法。通过算法构建多个马尔可夫链，使得它们的平稳分布与感兴趣的后验分布相匹配，这个过程称为MCMC收敛。

贝叶斯推断的核心术语（2）

  • 采样样本（Samples/Draws）：采样样本值是指从后验分布中抽取的参数值，用作后验分布的近似，并通过蒙特卡洛积分获得后验分布的经验估计和感兴趣的汇总统计量。其采样结果在计算机术语中也称为 trace。

  • 调试样本（Tune）：调试样本是指在MCMC抽样过程中用于达到平稳分布的初始阶段，此阶段的样本通常被丢弃，不在最终分析中使用。也叫做 Warmup 或 burn-in，燃烧样本。

  • 链(Chains)或轨迹(trace)：自单个MCMC链的一系列样本（或抽样值）；用于诊断收敛性以及程序在特定应用中的其他潜在问题。

  • 有效样本大小（Effective Sample Size, ESS）：有效样本大小是指与N个自相关样本具有相同估计力的独立样本数量。ESS常用于判断MCMC链中的抽样数量是否足以保证可靠的估计不确定性。

贝叶斯推断的核心术语（3）

  • R-hat（\(\hat R\)）：比较链间与链内变异的诊断量；接近 1 提示链间一致性较好，仍需结合其他诊断判断。

  • 最高密度区间（Highest Density Interval, HDI）：最高密度区间是贝叶斯统计中参数可信范围的估计。它包括后验分布中的一个区间，该区间内的每个点的密度都高于区间外的点。

  • 实际等效区间（Region of Practical Equivalence, ROPE）：预先定义的参数范围，范围内的值在研究情境中被视作实际等效于某个参考值。

  • 贝叶斯因子（Bayes Factor, BF）：贝叶斯因子量化了一个统计模型相对于另一个模型的证据强度。大于1的值表明相对于原始模型，替代模型得到了更多的支持。

老案例：Beta-Binomial 模型

仍然以随机点运动任务为例，每个试验中参与者判断正确的概率用 \(\theta\) 表示。

模型假设

  • 判断正确概率 \(\theta\) 服从 Beta 分布分布：

\[ \theta \sim \mathrm{Beta}(\alpha, \beta) \]

  • 在每次试验中，参与者的成功次数 \(Y\) 服从 Binomial 分布：

\[ Y \sim \text{Binomial}(n, \theta) \]

其中，\(n\)是试验的总次数，\(Y\)是成功次数。

模型设定

使用Beta-Binomial 模型来表示：

总试验数为n=10，成功次数为9 \((Y = 9)\)
先验分布为：\(\theta \sim \mathrm{Beta}(2, 2)\)
似然函数为：\(Y|\theta \sim \text{Bin}(n, \theta)\)

Stan 模型代码

Beta-Binomial 模型对应的 RStan 代码为：

# 准备数据  
stan_data <- list(N = 10,Y = 9)  

# 定义模型  
stan_model_code <- "  
data {  
  int<lower=0> N;       
  int<lower=0, upper=N> Y;  
}  
parameters {  
  real<lower=0, upper=1> theta;  
}  
model {  
  theta ~ beta(2, 2);  
  Y ~ binomial(N, theta);  
}  
"

采样和提取后验样本

采样结果保存在 fit 对象中；extract() 可以提取后验样本。

fit <- rstan::stan(
  model_code = stan_model_code,
  data = list(N = 10, Y = 9),
  chains = 4, iter = 2000, warmup = 1000,
  seed = 84735
)
draws <- rstan::extract(fit, pars = "theta")
sample_theta <- draws$theta

但在使用这些样本之前，需要先判断后验近似是否可信。

为什么要检查采样质量？

由于这些采样来自于 MCMC 算法，即马尔科夫链蒙特卡洛算法，而模拟采样方法的关键是 “近似”和 “收敛” 。

这就引出了以下问题：

  • 好的马尔可夫链是什么样的？
  • 如何判断马尔可夫链样本是否产生了合理的后验近似值？
  • 马尔可夫链样本量应该多大？

诊断的意义：确定好的trace的标准，为我们不知道真实的后验时作为标准进行推断。

诊断需要多种证据

在本节中，将重点介绍几种诊断方法：

  • 可视化诊断：轨迹图 (trace plot)和平行链 (parallel chains)。
  • 量化诊断指标：有效样本大小 ESS(effective sample size)、自相关性 (autocorrelation)和 \(\hat{R}\) (R-hat)。

这些诊断方法的使用应综合考虑。没有一种视觉或数值诊断方法是万能的，通常要一起考虑。

轨迹图（trace plot）

轨迹图 (trace plot) 是一种可视化方法，用于显示马尔可夫链的轨迹，即马尔可夫链在参数空间中的位置。
- 图中的横坐标是时间步长，纵坐标是参数的值。
- 轨迹图往往结合参数的后验分布一起展示，以便于观察采样样本对于参数分布的代表性。

正常的轨迹图

我们先来看一下正常的轨迹图是什么样：

  • 这是之前 Beta-Binomial model 的示例。
  • 图中：轨迹图看起来像一堆白噪声，没有明显的趋势或现象，这意味着链是稳定的。
  • 图中：展示了正常的参数后验分布的情况。

轨迹图问题 A：持续趋势

  • 5000 次迭代后仍有下降趋势，只探索了局部参数范围。
  • 持续趋势和强自相关表明链尚未充分探索后验。
  • 密度图可能高估中央区域，低估范围之外的可信值。

轨迹图问题 B：链在局部停滞

  • 局部出现接近平直的轨迹，说明链可能停留在某些参数值附近。
  • 局部强相关会造成某些区域过度采样。
  • 即使密度图看似接近目标分布，也需要检查轨迹和数值诊断。

轨迹图不理想时如何处理？

如果我们得到一个糟糕的轨迹图，如何进行补救📍：

    1. 检查模型。确定假定的先验模型和数据模型是否合适？
    1. 对数据链进行更多迭代。一些不理想的短期连锁趋势可能会在长期内得到改善。

马尔可夫性质与自相关

MCMC 的“无记忆性”指：给定当前状态后，下一状态不再依赖更早的状态。

  • 马尔可夫性质不等于相邻样本独立；相隔多步的样本也可能相关。
  • 自相关函数（ACF）描述相关性如何随滞后步数变化。
  • 有效样本量（ESS）描述相关样本在估计精度上相当于多少独立样本。

因此，评估采样质量需要同时关注链混合和估计精度。

自相关性（autocorrelation）

  • 链值 \(\theta_i\) 依赖于 \(\theta_{i-1}\)，也可能间接关联更早的链值。
  • 这种关联在混合良好的链中通常随滞后增大而减弱。
  • 正的自相关较强时，同样数量的抽样通常提供更少的有效信息。

直观类比：相距较近的链值，往往比相距较远的链值更相似。

快速衰减的自相关

  • 左侧为轨迹图，右侧为自相关图。
  • 滞后 0 的自相关为 1；滞后 1 时约为 0.5。
  • 自相关随滞后迅速下降，约在滞后 5 附近接近 0。
  • 这提示链在可信参数范围内混合较快。

补充：怎样理解滞后？

设一条链有 100 个样本 \(\theta_1,\ldots,\theta_{100}\)。

滞后 10 的相关性比较：

\[ (\theta_1,\ldots,\theta_{90})\quad\text{与}\quad(\theta_{11},\ldots,\theta_{100}). \]

两组均有 90 个配对值；滞后越大，可用配对数越少。

自相关估计应结合整条相关函数及其估计不确定性理解。

缓慢衰减的自相关

一个自相关糟糕的例子：

  • 自相关曲线的缓慢下降表明，链值之间的依赖关系不会很快消失。
  • 相差整整 20 步的马尔可夫链值之间存在大约 0.9 的相关性！
  • 由于其链值与前值的联系非常紧密，因此该链的混合速度很慢，需要很长时间才能充分探索后验的全部范围。
  • 因此，应该谨慎使用该链来近似后验。

快速混合与慢速混合

重要概念：Fast vs slow mixing Markov chains

  • 快速混合：指链表现出与独立样本的行为，即混合链值之间的自相关性迅速下降，有效样本大小比相当大。

  • 慢速混合：指链不具有独立样本的特征，即混合链值之间的自相关性下降非常缓慢，有效样本大小比很小。换句话说，链在后验可信值范围内 “缓慢”移动。

混合较慢时的处理策略

  1. 检查模型、参数化和采样警告；必要时改善参数化或调整采样设置。
  2. 在链已经能够探索目标分布的前提下，延长采样以提高估计精度。
  3. 抽稀（thinning）每隔若干次迭代保留一个样本，可减少存储量。

例如 thin = 10 保留 \(\{\theta_{10},\theta_{20},\ldots\}\)。

抽稀会丢失样本，不能修复未收敛，也不保证提高单位计算时间的 ESS。

有效样本量与有效样本量比率

ESS 表示：在估计某个后验量时，当前相关样本相当于多少个独立样本。

\[\text{ESS ratio}=\frac{N_{\mathrm{eff}}}{N}.\]

  • \(N\)：热身后保留的总样本数；\(N_{\mathrm{eff}}\)：有效样本量。
  • 示例：\(N=20000\)，\(N_{\mathrm{eff}}=6800\)，则比率为 \(34\%\)。
  • ESS 是估计精度的等效量，不是直接数出独立样本。
  • 正自相关常使 ESS 小于 \(N\)；负自相关可能使 ESS 大于 \(N\)。
  • 比率不能单独作为收敛标准，还需结合绝对 ESS、\(\hat R\) 和采样警告。

补充：ESS 的计算思想

对于平稳链，积分自相关时间和 ESS 的基本关系为：

\[\tau=1+2\sum_{k=1}^{\infty}\rho_k,\qquad N_{\mathrm{eff}}\approx\frac{N}{\tau}.\]

  • \(\rho_k\) 是滞后 \(k\) 时的自相关系数。
  • 实际计算需要估计并截断自相关序列，避免尾部噪声累积。
  • 使用软件提供的稳健估计；不要仅凭某一个滞后处 ACF 小于 0.1 就截断。
  • 多链分析还会结合链间信息，并分别关注 bulk ESS 和 tail ESS。

比较多条平行链

自相关和有效样本量仅针对于描述一条MCMC链的有效性。有多条并行的马尔可夫链时，不仅链内要稳定，多条链之间也需要有一致性。

如果四条链的结果并不一致，那么推断结果的可靠性就很难保证。

良好的并行链的结果：

  • 四条链产生的后验近似值几乎没有差别，这证明我们的模拟是稳定的。

迭代太少：链间密度仍有差别

为了便于比较和展示一个不好的并行链，我们用更短的马尔可夫链模拟来演示。

  • 运行四条并行链仅进行 100 次迭代，其中 50 次为warmup (见之前的词典解释)，因此最终产生 每条链 50 个后验样本，4 条链共 200 个。

  • 虽然这些链的轨迹图表现出相似的随机行为，但它们对应的密度图却不尽相同，因此产生的后验近似值也不尽相同。

这表明，如果我们只进行了 100 次迭代就停止模拟，那结果是不稳的。

相互冲突的平行链

一个糟糕的例子：

  • 四条平行链产生了相互冲突的后验近似值（中图）
  • 当我们将这些链组合在一起时，后验近似值不稳定且较差（右图）。
  • 因此，不同MCMC链参数值的范围和变异性远大于任何单个链中参数值的范围和变异性。

从变异比较到 R-hat

可直观地看出，所有链条上的数值变化与单个并行链条内部的数值变化之间的关系非常重要。具体来说

  • 在 “好的”马尔可夫链模拟中，所有并行链的变异性总和将与任何单个链内的变异性大致相当；
  • 在 “坏的”马尔可夫链模拟中，所有并行链的变异性总和可能超过每个链内的典型变异性

可使用 \(\hat{R}\) 量化综合链变异性和链内变异性之间的关系。

R-hat 的解释与边界

\(\hat R\) 通过比较链内与链间的变异评估多条链的一致性。

经典形式可概括为：

\[\hat R=\sqrt{\frac{\widehat{\mathrm{var}}^{+}}{W}},\]

其中 \(W\) 为链内方差估计，\(\widehat{\mathrm{var}}^{+}\) 综合链内与链间信息。

  • 理想值接近 1；现代诊断通常关注 rank-normalized split-\(\hat R\)。
  • 正式分析通常要求 \(\hat R<1.01\)，并结合 ESS 和发散诊断。
  • \(\hat R\) 接近 1 不能单独证明收敛。

参考：Stan diagnostics。

两个示例的 R-hat

示例 \(\hat R\) 解读
良好的平行链 约 1 链内与链间的变异较一致
相互冲突的平行链 5.35 链间差异远超链内典型波动

第二个示例提示平行链未产生一致的后验近似，不能据此直接进行后续推断。

注意：\(\hat R\) 不是方差比本身；不能将 5.35 直接解释为方差大了 5.35 倍。

采样设置：样本、链与热身

沿用 Beta-Binomial 模型：\(N=10\)，\(Y=9\)，先验为 \(\mathrm{Beta}(2,2)\)。

  • 运行 4 条链，每条链 iter = 2000。
  • 每条链 warmup = 1000，用于采样器调试，热身样本不进入后验分析。
  • 热身后共保留 \(4\times1000=4000\) 个样本。

思考：怎样描述后验分布？

后验分布描述给定数据与模型后，成功概率 \(\theta\) 的不确定性。

当你看到后验分布时，哪种表述更完整？

  1. 参与者判断正确的概率大约为 80%。

  2. 判断正确的概率集中在约 80% 附近，但其他取值仍有不同程度的可信度。

后验分布同时包含集中趋势和不确定性。

样本量增加后的后验

选项 b 同时描述集中趋势和不确定性，更完整地表达后验信息。

现在保持先验不变，把数据换成课程数据文件 data/beta-binmial.csv（118 次判断、正确 99 次，即 ACC 列求和 = 99）：

\[\theta\sim\mathrm{Beta}(2,2),\qquad Y\mid\theta\sim\mathrm{Binomial}(118,\theta).\]

根据共轭更新：

\[\theta\mid Y\sim\mathrm{Beta}(2+99,\ 2+118-99)=\mathrm{Beta}(101,21).\]

众数相近，不确定性不同

图中展示了这两种情况下的后验分布

黑线表示众数，即在后验分布中最可能出现的值

点估计之外还需要区间估计

  • 在这两种分布下，\(\theta\)最可能的取值都在83-84%左右

  • 如果只关注众数，两种截然不同的情况却会导致相似的结论❌

  • 但很明显，我们可以看到两图中\(\theta\)的分布范围是不同的

要同时看到\(\theta\)的集中趋势和离散趋势，可使用 95%的可信区间(credible intervals, CrI) 来描述\(\theta\)

95% 等尾可信区间

等尾可信区间（equal-tailed interval, ETI）可由后验分位数构造。

\[I_{95\%}=[q_{0.025},q_{0.975}].\]

对于 \(\mathrm{Beta}(101,21)\)，95% ETI 为 [\(0.756\), \(0.889\)]。

给定当前数据、模型和先验，\(\theta\) 落在该区间内的后验概率为 95%。

这不表示“95% 的参与者的成功概率落在该区间内”。

最高密度区间（HDI）

最高密度区间（highest density interval, HDI）包含指定的后验概率质量，并优先纳入密度较高的值。

  • ETI 的两侧尾部概率相等。
  • HDI 的区间内密度不低于区间外密度；在偏态分布中可能与 ETI 不同。

HDI 的密度阈值直觉

直觉理解：想象有一根水平的线从后验概率密度最高点往下滑，如果是95%HDI，则意味着黄色部分的面积占曲线下面积的95%

来源：HDI 示意图原始讨论。

95% CI 与 95% HDI

小结：先诊断，再推断

通过概率编程语言中的MCMC samplers完成对后验分布的近似后，我们可以开始进行推断统计。

但进行推断之前，首先要检查 MCMC 的质量。
- 可视化：直观地检查多个并行链的轨迹图和密度图，以确定模拟的稳定性和混合性。
- 数学指标：用有效样本量比、自相关性和 \(\hat{R}\)等数值诊断来补充这些视觉诊断。

均值、中位数与众数

在对后验进行推断中，要注意非正态分布后验的平均值、中位数和众数并不相等。

  • 其中众数为分布最高点对应的参数值
  • 中位数左右两侧分布的面积各占50%
  • 均值是参数值按后验密度加权的平均，可能受偏态和尾部影响。

从参数估计到假设与决策

后验估计回答：成功概率 \(\theta\) 可能取哪些值？

进一步的研究问题包括：成功概率是否高于随机水平？差异是否具有实际意义？

方法 回答的问题
HDI 哪些参数值位于高密度的可信范围内？

这些方法的解释和决策规则应分别说明。

研究问题：成功概率与随机水平

以 \(N=118\)、\(Y=99\) 为例，后验为 \(\mathrm{Beta}(101,21)\)。

研究问题：成功概率是否不同于随机水平 \(0.5\)？

\[H_0:\theta=0.5,\qquad H_1:\theta\ne0.5.\]

  • HDI 可用于检查 \(0.5\) 是否位于高密度可信范围内。
  • 如果关心“高于 0.5”，可直接计算 \(P(\theta>0.5\mid Y)\)。
  • 点零假设的 Bayes factor 需要单独定义相应模型，本讲不展开，见第 8 讲 §3.1。

通过 HDI 描述可信参数范围

沿用先验 \(\mathrm{Beta}(2,2)\) 和后验 \(\mathrm{Beta}(101,21)\)。

  • 95% HDI 包含后验分布中 95% 的概率质量。
  • 对本例单峰连续分布，HDI 优先包含密度最高的参数值。
  • 比较参考值 \(0.5\) 与 HDI，可以描述该参考值是否处于高密度可信范围。

HDI 的覆盖情况与点零假设的后验模型概率是不同的量。

单峰连续分布的 HDI 条件

计算 HDI

HDI 是后验分布中包含最高密度的区间，我们通常计算 95% HDI，这意味着该区间包含后验分布中 95% 的概率质量。HDI 的定义要求该区间 \([\theta_\text{low}, \theta_\text{high}]\) 满足以下条件：

  1. 对于任何 \(\theta\) 在区间 \([\theta_\text{low}, \theta_\text{high}]\) 外的点，它的密度都小于区间内的点的密度，即：

\[ f(\theta_\text{low} | \alpha, \beta) = f(\theta_\text{high} | \alpha, \beta) \]

  1. 该区间内的概率质量为 95%：

\[ \int_{\theta_\text{low}}^{\theta_\text{high}} f(\theta | \alpha, \beta) d\theta = 0.95 \]

HDI 不包含 0.5：如何解释？

本例 95% HDI 大约为 \([0.76,0.89]\)，不包含 \(0.5\)。

  • 在所选先验、似然模型和区间规则下，高密度可信范围位于随机水平之上。
  • 如采用“区间排除参考值”的决策规则，应事先说明规则与概率质量。
  • 这个结果不直接给出 \(P(H_0\mid Y)\)，也不等同于 Bayes factor。

HDI + ROPE：实际等效区间

ROPE（region of practical equivalence，实际等效区间）表示实践中可视作等效的参数范围。

本例设定：\(\mathrm{ROPE}=[0.4,0.6]\)。

  • 落在该范围内的成功概率，被本例的决策规则视作实际接近随机水平。
  • 该范围只是教学示例，应结合领域知识与研究目的预先设定。
  • 将 95% HDI 与 ROPE 比较，区分完全位于区间内、完全位于区间外和部分重叠。

HDI 与 ROPE 的三种关系

HDI 与 ROPE 的关系 按 HDI + ROPE 规则作出的判断
HDI 完全位于 ROPE 内 支持实践等效的判断
HDI 完全位于 ROPE 外 支持实践不等效的判断
HDI 与 ROPE 部分重叠 保留判断，当前精度不足以按该规则决策

比较时需同时注明 HDI 的概率质量和 ROPE 的上下界。

本例中的 HDI + ROPE 判断

本例 95% HDI 大约为 \([0.76,0.89]\)，ROPE 为 \([0.4,0.6]\)。

  • HDI 完全位于 ROPE 上方。
  • 按预设的 HDI + ROPE 规则，成功概率与随机水平存在具有实际意义的差异。
  • 这一解释依赖于模型、先验与 ROPE 的选择。

贝叶斯因子：相对证据的更新

贝叶斯因子是用于比较两种假设（通常是虚无假设和备择假设）相对支持程度的一个量化工具。它通过计算在两种假设下观察到的数据的概率，来评估这些假设的相对可信度。

从先验到后验，数据让备择假设的相对可能性发生了改变。

我们可以使用贝叶斯因子来量化数据对我们信念更新的程度：

\[ \begin{align*} \text{Bayes Factor} &= \frac{\text{posterior odds }}{\text{prior odds }} \\ &= \frac{\text{后验概率比}}{\text{先验概率比}} \\ &= \frac{P(H_1 | Y) / P(H_0 | Y)}{P(H_1) / P(H_0)} \end{align*} \]

  • \(BF_{10}\) = 1，收集到的数据并没有改变备择假设\(H_1\)的相对可能性
  • \(BF_{10}\) > 1，收集到的数据增加了备择假设\(H_1\)的相对可能性。BF越大，表明支持备择假设\(H_1\)的证据越强
  • \(BF_{10}\) < 1，收集到的数据削弱了备择假设\(H_1\)的相对可能性。BF越小，表明支持备择假设\(H_1\)的证据越弱

贝叶斯因子的常用解释尺度

贝叶斯因子 解读
> 100 极强的证据支持\(H_1\)
30 ~ 100 非常强的证据支持\(H_1\)
10 ~ 30 较强的证据支持\(H_1\)
3 ~ 10 中等程度的证据支持\(H_1\)
1 ~ 3 较弱的证据支持\(H_1\)
1 没有证据
1/3 ~ 1 较弱的证据支持\(H_0\)
1/10 ~ 1/3 中等程度的证据支持\(H_0\)
1/30 ~ 1/10 较强的证据支持\(H_0\)
1/100 ~ 1/30 非常强的证据支持\(H_0\)
< 1/100 极强的证据支持\(H_0\)

Source: 该表改编自胡传鹏等(2018)，源引用于Lee & Wagenmakers (2014)。

点零假设需要单独定义模型

连续参数模型下，单个点的概率为零：

\[P(\theta=0.5\mid Y)=0.\]

这不意味着点零假设无法比较。

  • 点零假设需定义为单独模型，并为模型赋予先验概率。
  • 本节继续演示另一种比较：参数落在区间内与区间外。
  • 两种比较对应不同假设，不能混用后验概率。

区间假设：比较区间内与区间外

定义互补的区间假设：

\[H_0:\theta\in[0.4,0.6],\qquad H_1:\theta\notin[0.4,0.6].\]

将 \(\mathrm{Beta}(2,2)\) 先验限制在两个区域内并分别归一化，可得到两个假设的条件先验。

\[BF_{10}=\frac{P(H_1\mid Y)/P(H_0\mid Y)}{P(H_1)/P(H_0)}.\]

在当前完整先验下，假设的先验概率来自相应区域的概率质量，不能直接假定为各 0.5。

由先验和后验概率质量计算 BF

令 \(p_0=P(0.4\le\theta\le0.6)\)，\(p_{0\mid Y}=P(0.4\le\theta\le0.6\mid Y)\)。

\[p_0=F_{\mathrm{Beta}(2,2)}(0.6)-F_{\mathrm{Beta}(2,2)}(0.4),\]

\[p_{0\mid Y}=F_{\mathrm{Beta}(101,21)}(0.6)-F_{\mathrm{Beta}(101,21)}(0.4).\]

\[BF_{10}=\frac{(1-p_{0\mid Y})/p_{0\mid Y}}{(1-p_0)/p_0}.\]

这与两个截断先验模型的边际似然比一致。

区间假设的实际计算结果

Code 
prior_h0 <- pbeta(0.6, 2, 2) - pbeta(0.4, 2, 2)
post_h0 <- pbeta(0.6, 101, 21) - pbeta(0.4, 101, 21)
bf_10 <- ((1 - post_h0) / post_h0) / ((1 - prior_h0) / prior_h0)
  • 区间内先验概率：0.296。
  • 区间内后验概率：2.135e-08。
  • \(BF_{10}=\) 1.970e+07；\(BF_{01}=1/BF_{10}\)。
  • 数据增强了区间外假设的相对证据，并不证明 \(\theta\) 等于 0.8。

Bayes factor 依赖先验和区间设定；应用中应报告其敏感性。

补充：低于 80% 的后验概率

直接计算成功概率低于 80% 的后验概率：

\[P(\theta<0.8\mid Y=99,N=118)=F_{\mathrm{Beta}(101,21)}(0.8).\]

Code 
post_left <- pbeta(0.8, 101, 21)

结果为 20.2%。该概率描述给定数据和模型后的参数不确定性。

互补方向假设的后验概率比

将两个互补的方向假设写为：

\[H_1:\theta<0.8,\qquad H_0:\theta\ge0.8.\]

  • \(P(H_1\mid Y)=\) 0.202。
  • \(P(H_0\mid Y)=\) 0.798。
  • 后验概率比为 \(P(H_1\mid Y)/P(H_0\mid Y)=\) 0.253。

在这两个区域中，后验概率更倾向于 \(\theta\ge0.8\)。

方向假设的先验概率比

在先验 \(\mathrm{Beta}(2,2)\) 下，使用相同的两个区域：

Code 
prior_left <- pbeta(0.8, 2, 2)
prior_odds <- prior_left / (1 - prior_left)
posterior_odds <- post_left / (1 - post_left)
bf_left_right <- posterior_odds / prior_odds
  • \(P(H_1)=\) 0.896。
  • \(P(H_0)=\) 0.104。
  • 先验概率比为 8.615。

先验概率应由当前的 Beta 先验计算，不能用区间长度直接替代。

从概率比到 Bayes factor

\[BF_{10}=\frac{\text{posterior odds}}{\text{prior odds}}.\]

本例中，\(BF_{10}=\) 0.029，其倒数 \(BF_{01}=\) 34.0。

  • \(H_1:\theta<0.8\)；\(H_0:\theta\ge0.8\)。
  • 相比于先验，数据提高了 \(H_0\) 相对于 \(H_1\) 的支持程度。
  • \(P(H_1\mid Y)\) 是后验概率；\(BF_{10}\) 描述相对证据的更新，两者不同。

这个结论基于 \(\mathrm{Beta}(2,2)\) 的条件先验；改变先验可能改变 Bayes factor。

总结与讨论

本节课利用后验分布完成三类任务：

  1. 诊断：检查轨迹、链混合、ACF、\(\hat R\)、ESS 与采样警告。
  2. 估计：报告集中趋势、可信区间与后验不确定性。
  3. 假设与决策：区分后验概率、HDI + ROPE 与 Bayes factor。

后验预测关注未来或复制数据；它与本节的参数估计属于不同任务。
